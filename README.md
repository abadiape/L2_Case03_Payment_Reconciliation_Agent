# Payment Reconciliation Agent

AI agent that reconciles payment settlements against an internal ledger, classifies exceptions, and routes them for human approval.

## Starting and using the payment reconciliation service

Using the CLI issue the command:

> python agent_skeleton.py

The agent starts, you see a prompt to enter a "Reconciliation period" date (year, month) first. Type the couple of dates being asked for or press enter twice to accept the defaults. Use the text below as a guide of what you should see:
Reconciliation period (YYYY-MM) [2026-03]:
Reference (today's) date [2026-04-05]:
